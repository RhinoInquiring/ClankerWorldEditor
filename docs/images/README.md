# README pictures

[Back to the README](../../README.md)

## Rendered (re-run any time)

`tools/readme-images.ps1 -Data "<client>\Data"` draws these with the editor's own renderer from the command line and
saves them here: `stormwind.jpg`, `city.jpg`, `map-picture.png`, `catalog.png`, `skins.jpg`.
Camera spots are in the script.

## Taken by hand

Pictures of the editor's panels. Save each here under the name given (JPEG keeps the repository small); the README has a commented slot
(`<!-- shot: name.png -->`) where it goes. Maximised window, default panel layout (View > Reset panel layout),
about 1600 px wide is plenty.

| File | What to show |
| --- | --- |
| `ui-overview.png` | The whole window on a busy spot (Northshire or Stormwind): viewport, Tools, Catalog, Inspector |
| `copy-paste.png` | Copy tool: a pinned paste on the ground with its orange footprint and blend band |
| `spawns-paths.png` | Creatures tool: a creature selected with its waypoint path (balls, tubes, blue arrows) |
| `npc-viewer.png` | NPC viewer on a character model, Appearance tab open |
| `zones.png` | Zones tool: coloured area borders, the Areas tab |
| `flights.png` | Flights tool: a path selected between two nodes |
| `compare.png` | A selection being compared (] key) with the COMPARE status line |
| `differences.png` | Catalog > Differences: the cards of a scanned version |
| `dungeon.jpg` | A WMO-only map open in the editor with its spawns (taken by hand; the script no longer draws it) |
